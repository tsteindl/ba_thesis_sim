# Algorithm code audit

Generated by `analysis/consolidated/audit.py`. It maps every algorithm the consolidated pipeline reports onto the function that is actually executed, and records how the diagnostic quantities are defined in that code.

## Reported algorithms

| manifest key | implementation | signature | pilot fed to the safeguard | N_guess / N_star |
|---|---|---|---|---|
| `brute` | `qmetrology.algorithms.find_phi_fixed_budget_brute_force` | `(rng, phi, phi_max, phi_min, budget, trace=None)` | none -- N is fixed at N_min = floor(pi/(2 phi_max)) | N_guess is NULL (no exploration), B_exploration = 0, N_star = N_min |
| `linear` | `qmetrology.algorithms.find_phi_fixed_budget_linear_search` | `(rng, phi, phi_max, phi_min, m_exploration, budget, lookback_window=5, safeguard=1, inc=1, trace=None)` | the scan history; the depth decision is the stopping rule, not a pilot estimate | N_guess = N_last - lookback_window*inc if the detector fired else N_last (before the safeguard); N_star = max(1, N_guess - s) |
| `binary_deep` | `qmetrology.algorithms.find_phi_fixed_budget_binary_search_deep` | `(rng, phi, phi_max, phi_min, m_exploration, budget, eps_target, conf=0.5, trace=None)` | (phi_acc, N_acc) -- the DEEPEST probe the bisection did not flag as an overshoot; sigma = 1/(2 N_acc sqrt(m')) | N_guess = N_acc = L; N_star = risk_optimal_depth(...) capped by the prior support N_max = floor(pi/(2 phi_min)) and floored at N_min |
| `reverse_eng_risk` | `qmetrology.algorithms.find_phi_fixed_budget_reverse_engineering_risk` | `(rng, phi, phi_max, phi_min, m_exploration, budget, eps_target, trace=None)` | (phi_hat_0, N_min) -- the single opening pilot; sigma = 1/(2 N_min sqrt(m')) | N_guess = floor(pi/(2 phi_hat_0)); N_star = risk_optimal_depth(...) capped by N_max = floor(pi/(2 phi_min)) |

Every one of these functions accepts an optional `trace=` collector (`qmetrology.trace.AlgorithmTrace`). The collector only records; it draws no random numbers, so a same-seed run with and without it returns identical `phi_hat` and budget use (`tests/test_consolidated.py::test_trace_neutrality`).

## The binary-search pilot mismatch

The handoff flags a material mismatch: the thesis pseudocode stores the deepest probe not classified as an overshoot (`phi_hat_acc`, `N_acc`) and supplies that pilot to the statistical safeguard, whereas `qmetrology.algorithms.find_phi_fixed_budget_binary_search_risk` supplies the opening probe (`phi_0`, `N_min`).

**Resolution.** The mismatch is resolved by ADDING an explicit function rather than by relabelling the existing one:

* `find_phi_fixed_budget_binary_search_deep` (new) — deepest accepted probe. This is the algorithm the consolidated pipeline reports, matching the thesis pseudocode and the `binary_deep` arm of `results/fine_sweep.csv`.
* `find_phi_fixed_budget_binary_search_risk` (unchanged) — opening probe. Kept, untouched, so every earlier study that cites it still reproduces.

Both call the same `_binary_search_explore`, so at one configuration they differ in exactly one input to `risk_optimal_depth`.

The reported algorithm therefore CHANGES relative to `find_phi_fixed_budget_binary_search_risk`; this is not merely added telemetry. The size of the change, on common seeds and identical configurations:

| U(0.01,0.1), eps=1e-03 | 10,000 | 100 | 0.5 | 65.60 | 65.60 | +0.00 | [65.18, 66.02] |

## Run constants

The scattered `R_TEST` values in the pre-existing scripts (`qmetrology/config.py` 50,000; `analysis/extensive_sweep.py` 40,000; `analysis/broad_dist_study.py` 30,000; `analysis/fine_sweep.py` 20,000) are NOT read by this pipeline. Every trial count, seed and grid comes from `qmetrology/manifest.py`, and every output row carries the `R`, `seed_test`, `seed_tune_blocks`, `algorithm`, `implementation_variant` and parameter dictionary it was produced with. The uncertainty layer reads `R` from the row.

## Definitions as implemented

```text
N_opt          = max(1, floor(pi / (2 phi)))            qmetrology/trace.py:n_opt
N_guess        per algorithm, see the table above; recorded BEFORE any safeguard
N_star         the depth the exploitation measurement actually ran at; null if it
               never ran
B_exploration  sum of N_i * m_i over every probe before the exploitation measurement,
               including repeated reverse-engineering pilot attempts after a zero
               estimate
exploration_share = B_exploration / nominal_budget
```

## Known limitation

`../thesis/*.tex` is not present in this checkout, so the audit is written against the pseudocode as described in the handoff and in `results/BS_METHOD_DECISION.md`, not against the .tex sources directly. The pilot/cap behaviour of each function is verified against the code, and the `binary_deep` implementation is asserted trial-for-trial identical to the reference arm of `analysis/fine_sweep.py` (`tests/test_consolidated.py::test_binary_deep_matches_fine_sweep`).
