Every one of these functions accepts an optional `trace=` collector (`qmetrology.trace.AlgorithmTrace`). The collector only records; it draws no random numbers, so a same-seed run with and without it returns identical `phi_hat` and budget use (`tests/test_consolidated.py::test_trace_neutrality`).

## The binary-search pilot mismatch

There is a material mismatch to resolve: the thesis pseudocode stores the deepest probe not classified as an overshoot (`phi_hat_acc`, `N_acc`) and supplies that pilot to the statistical safeguard, whereas `qmetrology.algorithms.find_phi_fixed_budget_binary_search_risk` supplies the opening probe (`phi_0`, `N_min`).

**Resolution.** The mismatch is resolved by ADDING an explicit function rather than by relabelling the existing one:

* `find_phi_fixed_budget_binary_search_deep` (new) — deepest accepted probe. This is the algorithm the results pipeline reports, and it matches the thesis pseudocode.
* `find_phi_fixed_budget_binary_search_risk` (unchanged) — opening probe. Kept, untouched, so every earlier study that cites it still reproduces.

Both call the same `_binary_search_explore`, so at one configuration they differ in exactly one input to `risk_optimal_depth`.

The reported algorithm therefore CHANGES relative to `find_phi_fixed_budget_binary_search_risk`; this is not merely added telemetry. The size of the change, on common seeds and identical configurations:

## Run constants

No trial count is hard-coded anywhere downstream. Every trial count, seed and grid comes from `qmetrology/manifest.py`, and every output row carries the `R`, `seed_test`, `seed_tune_blocks`, `algorithm`, `implementation_variant` and parameter dictionary it was produced with. The uncertainty layer reads `R` from the row.

## Definitions as implemented

```text
N_opt          = max(1, floor(pi / (2 phi)))            qmetrology/trace.py:n_opt
N_guess        per algorithm, see the table above; recorded BEFORE any safeguard
N_star         the depth the exploitation measurement actually ran at; null if it
               never ran
B_exploration  sum of N_i * m_i over every probe before the exploitation measurement,
               including repeated reverse-engineering pilot attempts after a zero
               estimate
exploration_share = B_exploration / nominal_budget
```

## Known limitation

`../thesis/*.tex` is not present in this checkout, so the audit is written against the pseudocode as reproduced in `thesis_code/`, not against the .tex sources directly. The pilot/cap behaviour of each function is verified against the code, and `binary_deep` is asserted trial-for-trial identical to an independent transcription of Algorithm 5 (`tests/test_consolidated.py::test_binary_deep_matches_fine_sweep`).
