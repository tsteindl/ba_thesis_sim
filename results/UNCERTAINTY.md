# Uncertainty of the reported numbers

_Generated by `analysis/uncertainty.py` from `results/story_curves.csv`. No simulation is re-run: every interval below is derived from the convergence rates already on disk._

## What each number's error bar is

- **Convergence rates** are binomial proportions over R = 40,000 independent trials. The Wilson 95% interval is at most **±0.49 percentage points** across the whole sweep (worst case, p = 0.5), and narrower wherever the rate is near 0 or 1.
- **Budgets to reach p\*** are *derived*: the convergence-vs-budget curve is log-interpolated to where it crosses p\*. Their Monte-Carlo uncertainty is obtained by parametric bootstrap (resample every curve point from Binomial(R, p̂)/R, re-interpolate, 2,000 replicates). At the 90% threshold the 95% half-width is a median **±1.57%** of the budget (90th percentile ±1.91%).
- **Budget ratios** inherit both curves' noise: median half-width **±2.16%** (90th percentile ±2.50%). This is **conservative**: all algorithms are evaluated on the same seed list, so trial *i* draws the same φ for every algorithm, and the true paired uncertainty is smaller than the independent resampling used here. How much smaller is directly measurable — brute force against itself has a ratio of exactly 1, yet the same independent bootstrap assigns it a half-width of **±2.09%** (median). Read the ratio intervals as an upper bound of roughly that magnitude.
- **Budget-grid discretisation** is a second, independent source. Re-deriving each crossing from the two half-density subgrids moves it by a median 1.23% (90th percentile 2.98%); log-linear interpolation error scales with the square of the grid spacing, so on the full 40-point grid this contributes roughly 0.31%.

**Rule of thumb for the thesis:** quote budgets to three significant figures and ratios to two decimals; treat differences below ~5% in a ratio as not resolved by this experiment.

## Not covered by these intervals

The grid search that selects each adaptive algorithm's parameters is itself random (tuned at R = 2,000 on seed 42). De-biasing removes the *bias* this causes — the winning configuration is re-validated on an independent seed — but not the *variance* of which configuration wins. That component cannot be recovered from the stored results; `analysis/tuning_stability.py` measures it directly by repeating the tuning on several seeds at the headline cells only.
